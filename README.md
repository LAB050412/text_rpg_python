# Python 텍스트 RPG — 6팀 통합본

공기민 (전투 시스템) + 현민우 (스토리·이동 시스템) 통합 버전입니다.

---

## 📁 파일 구성

같은 폴더에 다음 파일을 모두 두고 실행하세요.

| 파일 | 담당 | 설명 |
|------|------|------|
| `팀플_정리.py` | **공기민** | 직업·전투·몬스터·포션·맵 시스템 |
| `world.py`     | **현민우** | 세계관·지역(장소) 데이터 |
| `story.py`     | **현민우** | 오프닝·지역 묘사·엔딩 크레딧 |
| `movement.py`  | **현민우** | 장소 이름 입력 이동 + 공기민의 던전 호출 |
| `main.py`      | **현민우** | 전체 진입점 |

---

## ▶ 실행 방법

```bash
python main.py
```

플레이 흐름:
1. 오프닝 인트로
2. 직업 선택 (전사 / 궁수 / 도적)
3. 이름 입력
4. **마을**에서 시작 → 장소 이름 입력으로 던전 입장
   - **고블린 숲** → 클리어 시 **슬라임 부족** 개방
   - **슬라임 부족** → 클리어 시 **골렘 마을** 개방
   - **골렘 마을** → 보스(골렘 군주) 처치 시 엔딩
5. 마을에서 명령어: `상태` / `포션` / `종료`

---

## ⚠ 공기민 파일에 추가된 한 줄

공기민의 원본 파일 마지막 줄(`main()`)은
다른 파일에서 `import` 하면 자동으로 실행되어 버립니다.

그래서 우리 통합본의 `팀플_정리.py` 마지막 한 줄을 아래로 바꿔두었어요.

**원본 (공기민 원본):**
```python
main()
```

**수정 후 (이 폴더의 팀플_정리.py):**
```python
if __name__ == "__main__":
    main()
```

이렇게 하면:
- `python 팀플_정리.py` 로 단독 실행도 똑같이 됩니다.
- `python main.py` 로 통합 실행하면 import 충돌이 사라집니다.

> 공기민 코드의 **로직은 한 글자도 바꾸지 않았어요.** 표준 Python 관례인
> `if __name__ == "__main__":` 가드만 마지막 한 줄에 추가했습니다.

## 🔗 공기민 ↔ 현민우 연결 지점

`movement.py`에서 공기민의 코드를 이렇게 가져다 씁니다:

```python
from 팀플_정리 import enter_map, MAP_DATA, use_potion
```

| 가져온 것 | 용도 |
|-----------|------|
| `enter_map(player, MAP_DATA[..])` | 던전 입장 시 호출 → 웨이브 전투 진행 |
| `MAP_DATA["1"|"2"|"3"]` | 공기민의 맵 데이터 (고블린 숲·슬라임 부족·골렘 마을) |
| `use_potion(player)` | 마을에서 `포션` 명령어로 포션 사용 |
| `select_job()` | `main.py`에서 직업 선택용 |

`world.py`의 각 던전은 공기민의 `MAP_DATA` 키와 1:1 매칭:
```python
"고블린 숲":  { "map_key": "1", ... }
"슬라임 부족": { "map_key": "2", ... }
"골렘 마을":  { "map_key": "3", ... }
```

---

## 🗺 게임 진행 구조

```
   [마을] ────→ [고블린 숲]  (공기민 MAP_DATA["1"])
      │             ↓ 클리어
      │         [슬라임 부족] (공기민 MAP_DATA["2"])
      │             ↓ 클리어
      │         [골렘 마을]   (공기민 MAP_DATA["3"]) ← 보스
      ↑─────────────┘             ↓ 클리어
                                 엔딩
```

각 던전은 공기민이 만든 웨이브 시스템(웨이브 1·2·3)대로 진행됩니다.

---

## 🎮 명령어 정리

### 마을에서
- `고블린 숲` / `슬라임 부족` / `골렘 마을` — 던전 입장
- `상태` — 캐릭터 상태창
- `포션` — 포션 사용
- `종료` — 게임 종료

### 던전(전투) 중 — 공기민 시스템
- `1` — 공격 (몬스터 번호 선택)
- `2` — 포션 사용
- `3` — 도망 (성공률 40%, 성공 시 마을로 복귀)
